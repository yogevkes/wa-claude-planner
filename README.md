# WA-Claude Planner

> A self-hosted WhatsApp → Claude → Google Calendar personal planner (Windows-friendly Node.js daemon). Docs below are in Hebrew. [Privacy policy](PRIVACY.md)

דימון קטן ל-Windows שמאזין לקבוצת WhatsApp **"קבוצה שלי עם עצמי"**:
כל הודעה שתכתוב שם עוברת ל-Claude, הוא מעדכן את **Google Calendar** ואת רשימת המשימות, ועונה לך באותה קבוצה עם אישורים, תובנות ושאלות. בנוסף, כל בוקר וכל ערב נשלח סיכום.

```
אתה (WhatsApp) ──► הקבוצה ──► הדימון במחשב ──► claude -p ──► JSON עם פעולות
                                         │                                   │
                                         ◄── תשובה בקבוצה ◄── Google Calendar ◄┘
```

## מה צריך מראש
- **Node.js 20 ומעלה** (גרסת LTS מ-nodejs.org)
- **Claude Code** מותקן ומחובר: הפקודה `claude` צריכה לעבוד ב-PowerShell
- חשבון Google עם היומן שלך

## התקנה (פעם אחת)

### 1. התקנת הקוד
מחלצים את התיקייה למקום קבוע, למשל `C:\wa-claude`, ומריצים ב-PowerShell:
```powershell
cd C:\wa-claude
npm install
```

### 2. חיבור Google Calendar
1. נכנסים ל-https://console.cloud.google.com, יוצרים פרויקט חדש (למשל `wa-planner`).
2. **APIs & Services → Library** → מחפשים **Google Calendar API** → **Enable**.
3. **OAuth consent screen** → External → ממלאים שם ומייל → מוסיפים את עצמך כ-Test user.
4. ⚠️ **חשוב:** בסוף מעבירים את האפליקציה ל-**In production** (כפתור "Publish app"). אחרת Google מבטלת את ההרשאה כל 7 ימים. אין צורך באימות של Google; בזמן החיבור תופיע אזהרה "האפליקציה לא אומתה" → Advanced → Continue.
5. **Credentials → Create credentials → OAuth client ID → Desktop app** → מורידים את קובץ ה-JSON.
6. שומרים אותו בשם `data\google-credentials.json` (תיקיית `data` נוצרת בהרצה הראשונה; אפשר ליצור אותה ידנית).
7. מריצים:
   ```powershell
   npm run google-auth
   ```
   נפתח דפדפן, מאשרים, ובסוף יופיע "✅ היומן חובר".

### 3. הגדרות
בהרצה הראשונה נוצר `config.json` (העתק של `config.example.json`). הדברים העיקריים:

| שדה | מה זה |
|---|---|
| `groupName` | שם הקבוצה, בהתאמה מדויקת |
| `userContext` | **מומלץ למלא:** שעות עבודה, זמני נסיעה, הרגלים. זה מה שמאפשר ל-Claude לתת תובנות טובות |
| `morningBrief` / `eveningBrief` | זמני הסיכומים בפורמט cron. ברירת המחדל: 07:30 ו-21:30. מחרוזת ריקה מבטלת |
| `calendarId` | `primary` או id של יומן אחר (מודפס בסוף `google-auth`) |
| `protectNonBotEvents` | `true` = הבוט ישנה וימחק רק אירועים שהוא עצמו יצר |
| `defaultReminderMinutes` | תזכורת ברירת מחדל לאירועים עם שעה |
| `claudeModel` | `sonnet` (ברירת מחדל) או `opus` |
| `claudePath` | אם `claude` לא נמצא, שמים כאן נתיב מלא (מקבלים אותו מ-`where claude`) |
| `debounceSec` | כמה שניות לחכות כדי לאחד כמה הודעות רצופות לקריאה אחת |
| `pairingPhone` | אופציונלי: במקום QR, קוד צימוד. מספר בפורמט 9725XXXXXXXX |
| `watchChats` | השיחות והקבוצות שנבדקות כל שעה (ראו למטה) |
| `scanCron` | תדירות הבדיקה. ברירת מחדל: כל שעה עגולה |
| `scanDownloadMedia` | הורדה ופענוח של תמונות ו-PDF מהשיחות במעקב. ברירת מחדל: `true` |
| `scanMaxFiles` | כמה תמונות/PDF לכל היותר נפתחים בבדיקה אחת, החדשים קודם. ברירת מחדל: 12 |
| `scanQuietHours` | שעות שקטות שבהן אין בדיקה. ברירת מחדל: `[23, 7]`. הבדיקה הראשונה אחריהן מכסה גם את הלילה |

### 4. הרצה ראשונה וחיבור WhatsApp
לוחצים פעמיים על `windows\start.bat`. יופיע קוד QR:
בטלפון: **WhatsApp → הגדרות → מכשירים מקושרים → קישור מכשיר** → סורקים.
כשמופיע `Listening to group "קבוצה שלי עם עצמי"` שולחים הודעת בדיקה לקבוצה, למשל "מחר ב-10 פגישה עם דני".
בסיום סוגרים עם Ctrl+C.

> אם הקבוצה לא נמצאה: `npm run list-chats` מדפיס את כל הקבוצות וה-id שלהן. מעתיקים את ה-id ל-`groupJid` בקונפיג.

### 5. הפעלה אוטומטית (מחשב שדלוק תמיד)
לחיצה כפולה על `windows\install-autostart.bat`, ואישור חלון ההרשאות של Windows (פעם אחת).

הסקריפט רושם משימה ב-Task Scheduler שמפעילה את הבוט ברקע **כשהמחשב עולה, גם בלי כניסה לחשבון**. כך הבוט חוזר לבד גם אחרי הפעלה מחדש של עדכוני Windows. אם הבוט קורס, הוא עולה מחדש אוטומטית. אם משהו בהפעלה כזו לא עובד, אפשר לעבור להפעלה בכניסה לחשבון: `install-autostart.bat logon`.

הגדרות חשובות במחשב:
- **שינה: אף פעם** (הגדרות ← מערכת ← צריכת חשמל). בלפטופ, גם סגירת המכסה לא צריכה להכניס אותו לשינה.
- **נעילת מסך וכיבוי מסך מותרים.** הבוט ממשיך לרוץ.
- עדיף חיבור רשת בכבל.

ניהול:
- עצירה: `windows\stop.ps1`
- הסרת ההפעלה האוטומטית: `windows\uninstall-autostart.ps1`
- לוגים: `data\logs\app.log`

### העברה למחשב אחר
1. במחשב החדש מריצים `windows\install-prereqs.bat` (Node.js ו-Claude Code), ומתחברים פעם אחת ל-Claude Code. אם ההתקנה של Node.js דרך winget נכשלת, הסקריפט מוריד את ההתקנה הרשמית מ-nodejs.org, מאמת אותה ב-SHA256 ושומר לוג מלא ב-`data\logs\node-install.log`.
2. מעתיקים את כל התיקייה `wa-claude`, **כולל `data` ו-`config.json`**. כך לא צריך QR חדש ולא אישור Google מחדש.
3. **עוצרים את הבוט במחשב הישן** (`stop.ps1` או סגירת החלון, ואם הותקנה הפעלה אוטומטית גם `uninstall-autostart.ps1`). שני בוטים על אותו חיבור WhatsApp מנתקים זה את זה.
4. במחשב החדש: `setup.bat`, ואז `install-autostart.bat`.
5. `claudePath` לא צריך עדכון גם אם שם המשתמש ב-Windows שונה: אם הנתיב שב-`config.json` לא קיים במחשב החדש, הבוט משתמש אוטומטית ב-Claude Code של המשתמש הנוכחי (`%USERPROFILE%\.local\bin\claude.exe`) וכותב על כך אזהרה ב-`app.log`.

## משתמש נוסף (למשל בן/בת הזוג)
אפשר להריץ על אותו מחשב עוזר נפרד לאדם נוסף. לכל אחד יש WhatsApp, יומן Google, מנוי Claude, קבוצת "עם עצמי", שיחות במעקב וסיכומים משלו. הנתונים של כל משתמש נשמרים בתיקייה `instances\<שם>\`.

**התקנה, יחד עם האדם הנוסף (כ-10 דקות):**
1. מכינים מראש: בטלפון שלו/שלה יוצרים קבוצת WhatsApp עם עצמו/ה, ונרשמים למנוי Claude משלו/ה.
2. לחיצה כפולה על `windows\new-user.bat`, ומקלידים שם קצר באנגלית (למשל `roni`). האשף עובר על חמישה שלבים:
   - **Claude:** נפתח חלון של Claude Code, מתחברים לחשבון Claude **שלו/ה** ואז כותבים `/exit`.
   - **הגדרות:** נפתח Notepad. ממלאים את `groupName` (שם הקבוצה עם עצמו/ה), את `watchChats` ואת `userContext`, שומרים וסוגרים.
   - **Google:** מתחברים לחשבון Google **שלו/ה** ומאשרים גישה ליומן.
   - **WhatsApp:** בחלון חדש מופיע QR, וסורקים אותו **מהטלפון שלו/ה**. שולחים הודעת בדיקה לקבוצה, וכשמגיעה תשובה סוגרים את החלון.
   - **הפעלה אוטומטית:** מאשרים את חלון ההרשאות של Windows.

**פקודות לפי משתמש:** כל הסקריפטים מקבלים את שם המשתמש כפרמטר. בלי שם, הם פועלים על המשתמש הראשי.

| פעולה | פקודה |
|---|---|
| הרצה גלויה (QR, בדיקות) | `windows\start.bat roni` |
| חיבור מחדש ליומן | `windows\google-auth.bat roni` |
| התחברות מחדש ל-Claude | `windows\claude-login.bat roni` |
| רשימת קבוצות ואנשי קשר | `node src\index.js --list-chats --instance roni` |
| עצירה | `powershell -File windows\stop.ps1 -Instance roni` (או `-All` לכולם) |
| הסרת הפעלה אוטומטית | `powershell -File windows\uninstall-autostart.ps1 -Instance roni` |
| לוגים | `instances\roni\data\logs\app.log` |

**פרטיות:** הבוט של כל משתמש רואה רק את החשבון שלו, ושולח רק לקבוצה שלו. אין שיתוף מידע בין המשתמשים. ה-QR נסרק רק מהטלפון של בעל החשבון, והבוט מופיע אצלו ב"מכשירים מקושרים", כך שהוא יכול לנתק אותו בכל רגע.

## עדכון לגרסה חדשה
לחיצה כפולה על `windows\update.bat`. הסקריפט מוריד את הגרסה האחרונה מ-GitHub ומעדכן את הקוד, בלי לגעת ב-`config.json`, ב-`data\` וב-`instances\`. אחרי העדכון מפעילים מחדש את המחשב, או עוצרים ומפעילים את הבוטים.

## בדיקה שעתית של שיחות חשובות
כל שעה הבוט עובר על ההודעות החדשות בשיחות שב-`watchChats`, כולל ההודעות שלך בהן, ושולח לקבוצה הודעה (🔎) **רק אם משהו דורש ממך פעולה או תיאום**: שאלה שלא ענית עליה, בקשה, החלטה, לוגיסטיקה, דדליין, או התנגשות עם היומן. אם אין כלום, לא תקבל הודעה.
- **היומן לא משתנה מהבדיקה הזו.** הבוט רק מציע, למשל "📅 להוסיף: אסיפת הורים – יום ד׳ 25.11 18:00?". עונים בקבוצה "כן" או "כן, תוסיף" והאירוע נכנס.
- משימות המשך ("לענות לאמא לגבי שישי") נכנסות לרשימת המשימות אוטומטית, ומופיעות בסיכום הערב.
- כשצריך לענות, הבוט מציע נוסח תשובה (✍️) להעתקה. **הוא אף פעם לא שולח הודעות לשיחות האלה.**
- **תמונות ו-PDF מהשיחות יורדים ומפוענחים:** הזמנות, הודעות מהגן או מבית הספר, אישורי תורים, חשבונות, מסמכים מעורכי הדין, צילומי מסך. תמונות רגילות (אנשים, אוכל, נוף) מדולגות בשקט. אפשר לכבות עם `"scanDownloadMedia": false`. סרטונים לא מפוענחים, והודעות קוליות רק מסומנות ככאלה.

**התאמת השמות:** שיחות פרטיות מזוהות לפי השם השמור באנשי הקשר, וקבוצות לפי שם הקבוצה. אחרי הקישור הראשון כדאי להריץ:
```powershell
npm run list-chats
```
הפקודה מציגה ✅ או ❌ לכל שיחה במעקב. אם שיחה פרטית לא זוהתה, מוסיפים לה מספר טלפון בקונפיג:
```json
"watchChats": ["אמא", { "name": "בן/בת הזוג", "phone": "972500000000" }, "המשפחה- קבוצה"]
```
בקבוצה אפשר גם לבדוק עם `/שיחות` אילו שיחות כבר קלטו הודעות.

## כשהמחשב כבוי או בשינה
- הודעות שנכתבו בזמן שהמחשב היה כבוי מגיעות כשהוא חוזר, עד 72 שעות אחורה (`catchUpMaxHours`), ומעובדות יחד. Claude מפרש "מחר" לפי שעת **שליחת** ההודעה.
- אם המחשב היה כבוי בשעת סיכום הבוקר, הסיכום נשלח באיחור כשהמחשב עולה (עד 12:00).
- אחרי חזרה משינה החיבור ל-WhatsApp מתחדש אוטומטית.

## בטיחות ופרטיות
- ל-Claude נשלחות רק ההודעות מהקבוצה שלך ומהשיחות שב-`watchChats`, כולל ההודעות של האנשים האחרים בהן. שאר הצ'אטים לא נשמרים ולא נקראים.
- תוכן השיחות במעקב נשמר מקומית ב-`data\inbox.json`, עד 80 הודעות אחרונות לשיחה. תמונות ומסמכים שהורדו נשמרים ב-`data\work\media` ונמחקים אוטומטית אחרי 7 ימים.
- Claude רץ עם כלי אחד בלבד: **Read**, לקריאת תמונות ו-PDF ששמרת בתיקיית העבודה. אין לו Bash, אין עריכת קבצים ואין גישה ל-MCP אחרים. כל הפעולות ביומן מבוצעות ע"י הקוד, לפי JSON ש-Claude מחזיר.
- כל שינוי ביומן נשמר כך שאפשר לבטל אותו עם `/בטל`, כולל שחזור של אירוע שנמחק.
- החיבור ל-WhatsApp לא רשמי (Baileys). הבוט רק קורא ושולח לקבוצה שלך עם עצמך, כך שהסיכון לחסימה נמוך, אבל הוא לא אפסי.
- קבצים רגישים נמצאים ב-`data\`: חיבור WhatsApp (`wa-auth`) וטוקן Google. לא משתפים את התיקייה הזו.

## תקלות נפוצות
| בעיה | פתרון |
|---|---|
| `Could not start Claude CLI` או `The system cannot find the path specified` | מריצים `where claude` ומעתיקים את הנתיב ל-`claudePath` |
| `install-prereqs.bat` נכשל בהתקנת Node.js (למשל קוד 1603) | הסקריפט מנסה שוב עם ההתקנה הרשמית. הסיבה המדויקת מופיעה ב-`data\logs\node-install.log` |
| `curl: (35) ... CRYPT_E_NO_REVOCATION_CHECK` | המחשב לא מצליח להגיע לשרתי בדיקת ביטול התעודות (לרוב בגלל אנטי-וירוס או סינון רשת). הסקריפטים כבר מדלגים על הבדיקה הזו, ושרשרת התעודה עדיין נבדקת |
| `Google is not authorized` / `invalid_grant` | `npm run google-auth` שוב. ודא שהאפליקציה ב-In production |
| הבוט לא מגיב | בודקים את `data\logs\app.log`. אם יש `logged out`, מוחקים את `data\wa-auth` ומריצים `windows\start.bat` לסריקה מחדש |
| הקבוצה לא נמצאה | `npm run list-chats` ומגדירים `groupJid` |
| שיחה במעקב לא נקלטת | `npm run list-chats`. אם יש ❌, מוסיפים `phone` לשיחה הזו ב-`watchChats` |
| הודעות קוליות | עדיין לא נתמכות. הבוט יבקש לכתוב בטקסט |
